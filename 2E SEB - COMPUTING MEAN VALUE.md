## SEB - COMPUTING MEAN VALUE

---

### AIM  

To Write a python program to define a function that accepts 3 values and return its mean value .

---

### ALGORITHM

1.Algorithm to Find the Mean of 3 Numbers Using a Function
Begin the program.

2.Define a function find_mean(a, b, c):

3.Inside the function, calculate the mean.
 
4.Return the mean.

5.Input three numbers from the user.

6.Call the function with the input values.

7.Display the returned mean value.

8.End the program.

---

### PROGRAM

def result(a,b,c):

    mean=(a+b+c)/3

    return mean


a=int(input())

b=int(input())

c=int(input())

print("mean is",result(a,b,c))
